# Global Media Discovery 2.1.0

This release adds production-ready, permission-gated Simkl Calendar v2 TV
evidence support. The integration uses a public Client ID only and never uses a
Client Secret, access token, watch history, ratings, memos, or other user data.

GMD retains only date-first television evidence relevant to its product:

- original series premieres;
- season premieres;
- mid-season, season, and series finales.

Ordinary episode airings are ignored. Simkl IDs are treated as evidence, and
cross-provider claims must pass the same conservative compatibility rules as
other sources. Conflicting identifiers are never merged automatically.

Simkl remains disabled after installation and upgrade. Operators can run the
read-only `gmd simkl test` probe, but publication requires both a configured
Client ID and `gmd simkl enable --permission-confirmed` after receiving provider
approval for retained normalized public evidence.

Title details can now select the exact event opened from the calendar, allowing
season-premiere and finale evidence to remain visible and attributable.
