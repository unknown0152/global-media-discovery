# Global Media Discovery 1.3.0

This is the first fully packaged public GitHub release of Global Media
Discovery. It contains a self-extracting VPS installer, source archive, release
manifest, and SHA-256 checksums.

## Highlights

- Adds explicit date meanings and distinguishes single-source, corroborated,
  disputed, and unverified premiere dates.
- Shows provider confidence, observation time, selected-date support, and the
  day difference for conflicting reports.
- Adds transparent coverage views by year, source, country, and active date.
- Uses Tailwind CSS 4.3.3 and locally vendored HTMX 4.0.0-beta6.
- Keeps the public API strictly GET/HEAD-only with a read-only SQLite mount.
- Preserves data and secrets during upgrades and fixes Caddy lock handling.
- Includes 40 automated tests plus compile, JavaScript, shell, Compose,
  installer-payload, and starter-database validation gates.

## Install

Download the installer and checksum file attached below, then verify and run:

```bash
grep global-media-discovery-installer-1.3.0.run \
  global-media-discovery-SHA256SUMS-1.3.0.txt | sha256sum -c -
sudo bash global-media-discovery-installer-1.3.0.run
```

Existing `/opt/global-media-discovery/data` and `secrets` are preserved during
an upgrade. See the [operations guide](https://github.com/unknown0152/global-media-discovery/blob/v1.3.0/docs/OPERATIONS.md)
for backup, recovery, credentials, and routine management commands.
