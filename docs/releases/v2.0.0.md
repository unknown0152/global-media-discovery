# Global Media Discovery 2.0.0

Version 2.0 is a production-runtime migration that preserves the catalog,
collector, identity rules, evidence history, and public API contract.

## Highlights

- React 19.2.8 and strict TypeScript 7.0.2 frontend.
- Vite 8.2.2 using its unified Rolldown production pipeline.
- TanStack Query, Router, and Virtual for server state, bookmarkable filters,
  and efficient result rendering.
- Go 1.27 serves the embedded website and every read-only API response.
- The Python collector remains the sole SQLite writer and publishes only
  validated staging databases through atomic replacement.
- Separate public and collector images prevent the API from receiving provider
  credentials, source egress, or a writable catalog mount.
- Country selection and Reset are controlled exclusively by URL/application
  state, fixing browser-restored selection regressions.

Existing installations can run the 2.0.0 installer normally. Catalog data,
backups, provider credentials, public settings, and the optional Seerr handoff
are preserved during upgrade.
