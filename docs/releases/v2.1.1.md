# Global Media Discovery 2.1.1

This compliance release publishes the previously tested Simkl Calendar v2 TV
evidence integration under Simkl's current official API rules.

GMD uses only Simkl's public, edge-cached Calendar v2 file. It does not call
OAuth `/sync/*` endpoints, read user watchlists, or use the Client Secret, so
the user-library activity and `date_from` sync loop does not apply.

Every result containing Simkl evidence now visibly names Simkl, displays its
official mark, and links directly to the item-specific Simkl page. A global
schedule-evidence credit remains visible in the footer.

The operator must explicitly accept Simkl's API rules and confirm that the
deployment is non-commercial, below the published revenue threshold, or
appropriately licensed before enabling collection.
