# Global Media Discovery 1.4.0

GMD 1.4.0 connects date-first television discovery to an existing Seerr
installation without weakening either product's security boundary.

## Highlights

- Title details can show **Open in Seerr** when the catalog has a verified TMDB
  identity and the operator has configured a public Seerr URL.
- Seerr continues to own sign-in, user permissions, quotas, season selection,
  approvals, and request creation. GMD stores no Seerr API key and its public
  API remains GET/HEAD-only.
- Records without a verified TMDB identity are explained clearly and are never
  mapped by fuzzy title similarity or a guessed provider ID.
- `gmd seerr` safely shows, enables, or disables the handoff and verifies the
  target before changing the deployment.
- TheTVDB integer-valued IDs are now accepted during window scans and remote-ID
  enrichment, preventing that provider payload shape from aborting its pass.

## Upgrade

Back up the current catalog, download the installer and checksum file from this
release, verify the checksum, and run the installer. Existing data, provider
credentials, and any configured Seerr URL are preserved.

After upgrading, enable the integration with the browser-facing URL users
already use for Seerr:

```bash
sudo gmd seerr https://seerr.example.com
```

No Seerr credential is required. Run `sudo gmd seerr off` to disable it.

## Validation

The release includes regression coverage for verified-ID handoff, unmatched
titles, credential-bearing URL rejection, API read-only enforcement, TheTVDB
integer IDs, provider failure isolation, conservative reconciliation, atomic
publication, database integrity, frontend parsing, and installer behavior.
