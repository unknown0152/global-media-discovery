## Starter catalog

The bundled `seed/catalog.sqlite3` is a compact normalized demonstration
catalog generated from proof-of-concept exports supplied for this project. It
contains the fields and source evidence required to render the date-first
catalog. It does not include the original raw export files.

## Web libraries

The compiled interface includes Tailwind CSS 4.3.3 and a locally vendored copy
of HTMX 4.0.0-beta6. Both projects are distributed under the MIT license.
Neither library is loaded from a third-party CDN at runtime.
