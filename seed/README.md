# Bundled starter catalog

`catalog.sqlite3` is a compact, normalized starter catalog for 1–13 August
2026. It was built from the proof-of-concept TMDB and TheTVDB exports supplied
for this project. It contains only the fields, identifiers, evidence, and
attribution needed by Global Media Discovery; the original raw provider
exports are not redistributed in the installer.

The scheduled collector replaces and extends this starter data using the API
credentials configured during installation and TVmaze's public schedule API.
